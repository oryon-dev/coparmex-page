## Resumen en una línea

Sitio institucional en Astro + Tailwind, con frontend casi completo (9 páginas), pero **sin CMS, sin formularios funcionales y sin contenido dinámico**: la parte "autogestionable" del plan original no se construyó.

> Los documentos 04 y 05 contienen información comercial (tarifas, montos). Conviene retirarlos de este repositorio antes de compartirlo con terceros.
